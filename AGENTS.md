## Project

**omp-study** is an interactive guide to **harness engineering** — building the
runtime that turns a raw LLM into a capable coding agent.

Repo: <https://github.com/123jimin-vibe/omp-study>

Durable product behavior is governed by the worklog specifications.

## Tracking mistakes
